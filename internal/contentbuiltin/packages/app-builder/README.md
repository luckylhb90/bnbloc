# App builder

A built-in expert shipped with bnbloc. It builds interactive apps (polls,
surveys, sign-up sheets, forms, boards) by conversation: a short interview,
a mobile-first page with the app SDK that bnbloc publishes as a site
deliverable after the turn, and, later, a report on the answers read with
the `app_data` room tool. It wears the Interactive apps skill pack and
offers the App starters prompts as its quick prompts.
