# Expert builder

A built-in expert shipped with bnbloc. It creates and improves experts, skill
packs and prompt packs by conversation: a short interview, a draft in `drafts/<name>/`
of its workspace, a quick try, and a save to the member's Library on their
confirmation (the `save_component` room tool, or "Save as expert" / "Save
as skill pack" / "Save as prompt pack" under the turn's deliverables when
the agent has no room tools).
